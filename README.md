> **Mood-Aware** is an intelligent wellness ecosystem that bridges the gap between digital activity and emotional well-being. By integrating your existing digital life (Notion, Spotify, Duolingo, etc.) with proactive mood tracking and 3D visualization, Mood-Aware provides a holistic view of your mental state and helps you optimize your daily routines.

---

## 🌟 Key Features

### 1. 🌈 3D Immersive Aura
Experience your emotional state through a real-time, 3D generative "Aura" built with **React Three Fiber**. The aura's colors, movement, and intensity shift based on your recent mood logs and productivity scores.

### 2. 🧠 AI Wellness Planner
Get personalized daily plans generated by AI that adapt to your emotional state. Feeling low? The planner suggests gentle activities. High energy? It pushes you toward your complex goals.

### 3. 📒 Notion Reflection Sync
Seamlessly sync your deep-work reflections and daily logs from **Notion**. The dashboard displays your recent Notion entries alongside your mood trends, providing context to your emotional data.

### 4. 📊 Unified Dashboard
- **Mood Trends**: Visualize your emotional journey over time.
- **Habit Tracking**: Monitor daily routines (Routine follow-through, Physical activity, Screen time).
- **Integration Hub**: View stats from connected services like Spotify, Duolingo, and LeetCode.

### 5. 🛠️ Integration Ecosystem
- **Notion**: Fetch and display daily reflections and highlights.
- **Spotify**: (WIP) Mood-based playlist suggestions and listening history.
- **Learning**: (WIP) Tracking Duolingo streaks and LeetCode progress to correlate learning with mood.

## 🛠️ Tech Stack

### Frontend
- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + shadcn/ui
- **3D Graphics**: Three.js + React Three Fiber (R3F)
- **State Management**: React Query (TanStack) + Zustand

### Backend
- **Runtime**: Node.js + Express
- **Language**: TypeScript
- **Database**: PostgreSQL (via Supabase)
- **ORM**: Drizzle ORM
- **Authentication**: Passport.js (Local & Session-based)

### Protocols
- **MCP (Model Context Protocol)**: Used for secure, context-aware AI interactions.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- PostgreSQL (or a Supabase project)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/3132Ganesh/Mood-Aware.git
   cd Mood-Aware
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Environment Setup**
   Create a `.env` file in the root directory:
   ```env
   DATABASE_URL=your_postgres_url
   SESSION_SECRET=your_random_secret
   NOTION_TOKEN=your_notion_api_token
   NOTION_DATABASE_ID=your_notion_db_id
   ```

4. **Initialize Database**
   ```bash
   npm run db:push
   ```

5. **Start Development Server**
   ```bash
   npm run dev
   ```
   The app will be available at `http://localhost:5000`.
